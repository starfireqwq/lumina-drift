## 一、版本演進總覽

從 `v1.2.0` 到 `v1.3.0` 是 Lumina Drift（流光）架構與創作體驗全面躍升的大版本迭代，可分為兩個主要階段：

1. **第一階段（`v1.2.0 → v1.2.8-beta`，106 筆提交）**：完成 CSP 等級 2D 動畫全套管線（Phase A–E）、濾鏡系統重構與 F1–F3 濾鏡庫、筆刷引擎 v2（含 ABR/SUT 匯入）、對齊與參考線系統（L1–L3）、外掛系統三代演進（API v2 → v2.5 → v3.0 桌面 Bridge／Loopback MCP）、多人房間角色權限（ACL）、跨伺服器主帳號與全新聯機入口畫廊。
2. **第二階段（`v1.2.8-beta → v1.3.0`，9 筆提交）**：加入 Procreate 筆刷匯入與筆劃管線升級、程序化漫畫對話框幾何引擎、六項 Procraft 風格多指觸控手勢與手機／平板浮動介面人體工學優化、升級版液態玻璃光學質感與全新「炫彩玻璃（Chromatic Glass）」RGB 流動模式，以及離線／線上工作區隔離與復原機制修復。

## 二、十大核心更新詳解

### 1. 🖐️ Procraft 風格觸控手勢與行動端交互全面升級
- **六項全新多指觸控手勢**（均可在「設定 → 筆壓測試」獨立啟閉與微調）：
  - **雙指快捏符合畫面**：快速向內捏合自動重置縮放與旋轉，使畫布完整置中顯示。
  - **四指輕點全螢幕專注模式**：隱藏／恢復所有工具列、分頁與浮動島，右上保留退出膠囊，亦支援再次四指輕點或按 `Esc` 恢復。
  - **雙指／三指長按連續復原與重做**：兩指按住持續復原、三指按住持續重做。
  - **單指長按行為可切換（快捷輪盤／吸色環）**：預設維持快捷輪盤，可切為即時吸色模式（附雙色對比浮動吸色環 `TouchEyedropperLoupe` 與即時 HEX 數值），並可自訂長按延遲（250ms–1000ms）。
  - **三指下滑剪貼選單**（`TouchClipboardMenu`）：快速喚出剪下、複製、複製全部、再製、貼上與清除圖層選單。
  - **僅觸控筆作畫模式**：支援「正常繪畫（預設）」、「僅觸控筆：單指平移」與「僅觸控筆：忽略單指防誤觸」，且同時保留完整多指手勢。
- **視圖旋轉手勢與回正**：
  - 支援雙指旋轉畫布；當畫布處於旋轉角度時，工具列自動顯示「回正」按鈕一鍵歸零至 0°。
- **手機與平板人體工學佈局**（`TouchCanvasChrome`、`DockSystem`）：
  - 修正手機（390×844）與平板（1024×768）底部浮動工具島、側邊筆刷島與貼圖鈕零重疊；底部工具島抓手改為滴管捷徑。
  - 側邊筆刷島支援上下拖曳調整拇指舒適高度（自動記憶位置）與拖曳即時筆刷圓點預覽氣泡。
  - 底部工具島支援安全區距與下滑收合／上滑展開；抽屜面板支援拖曳手勢關閉。
  - 手機橫放維持手機版面，桌面模式改由使用者手動切換，滑鼠桌面裝置不再顯示多餘切換選項。

### 2. ✨ 液態玻璃光學升級、「炫彩玻璃」模式與動態控制系統
- **升級版液態玻璃（Liquid Glass）**：去除毛玻璃灰霧感，改用高透光光學玻璃層、曲率高光與雙層折射亮線，在明暗主題下皆呈現立體通透質感。
- **全新「炫彩玻璃（Chromatic Glass）」模式**：結合液態玻璃質感與 16 秒緩慢流動的 RGB 虹彩光影，並在關閉介面動態時自動靜止以降低干擾與耗電。
- **介面動態與主題系統**：新增 `theme/motion.ts` 統一控制介面動畫強度與開關，完整支援 7 種主題 × 6 種表面材質自由組合，四語系（繁體中文／簡體中文／英文／日文）同步補齊。

### 3. 🖌️ 筆刷引擎 v2、跨軟體筆刷匯入與畫布渲染升級
- **筆刷引擎 v2 動態與混合系統**：
  - 新增共享筆刷動態結構與每通道動態評估器（壓感、速度、傾斜等），升級 `stroke.worker.ts` 支援濕混（Wet Mix）、材質紋理（Texture）與雙筆刷（Dual Brush）。
  - 全面升級 `BrushEnginePanel` 介面並補齊四語系與說明文件。
- **三大專業軟體筆刷格式匯入**：
  - **Procreate**（`procreate-parser.ts`）：支援 `.brushset` / `.brush` 匯入與參數解析。
  - **Photoshop**（`abr-parser.ts`）：支援 ABR v6 `desc` / `patt` 結構解析。
  - **Clip Studio Paint**：支援 `.sut` SQLite3 `Variant` / `Effector` 欄位解析。
- **數位板輸入與畫布顯示品質**：
  - 新增 `inputPreferences.ts` 與強化 `tabletInput.ts`、`stabilizer.ts`，改善壓感連續性與落筆手感。
  - 強化 `MipmapView.ts`：縮小檢視畫布時改採 Mipmap 層級取樣，消除縮放線稿鋸齒。
  - 最佳化大畫布 GPU 上傳管線：確保 1:1 像素寫入位元精確，並跳過多餘的本地操作重播。

### 4. 🎬 CSP 風格專業 2D 動畫系統（Phase A–E 完整落地）
- **Phase A — CSP 式時間軸與播放核心**：
  - 「新增賽璐珞格」直接建立於播放頭位置（預設不順移後續關鍵畫格）；若當前賽璐珞為資料夾，會自動複製內部資料夾與空圖層結構。
  - 支援「秒 + 幀」（如 `0+5`）與幀號一鍵切換、自訂時間軸總長、空白格（Blank Frame）、最長可達全時間軸的長定格（Hold）。
  - 洋蔥皮升級為三種視覺模式（平塗色、保留明暗、淡出原畫），前後最多各 10 格。
  - 播放改用 `requestAnimationFrame` 顯示時鐘計時（修正舊版 `setInterval` 漂移問題），並實作關鍵幀變形圖層的**原位作畫**。
- **Phase B — 賽璐珞管理工具與行動端時間軸**：
  - 支援賽璐珞標記（`○` / `●`）、備註文字與時間軸標籤。
  - 支援重複賽璐珞（群組一次復原）、序號批次重新命名、快速跳轉至指定幀／關鍵幀、翻頁檢視（Flipbook）與專用快捷鍵。
  - 針對手機螢幕設計底部抽屜式動畫時間軸版面。
- **Phase C — 關鍵幀編輯與動態路徑**：
  - 新增不透明度關鍵幀、貝茲緩動預設曲線與仿射變換輔助工具。
  - 畫布上可直接拖曳關鍵幀控制點（純 metadata 復原不影響像素紀錄），並提供本地端關鍵幀動態路徑疊層預覽。
- **Phase D — 離線專業級動畫匯出**：
  - 全新 `AnimationExportModal`，支援基於瀏覽器 `VideoEncoder` + `mp4-muxer` / `webm-muxer` 的離線 MP4 / WebM 影片封裝。
  - 支援逐幀關鍵幀變形算圖、透明背景合成、線稿二值化輸出、序列圖 TGA / BMP 編碼器，以及 Electron 桌面版指定資料夾輸出 IPC。
- **Phase E — 2D 攝影機、透光桌 v2 與本地音軌**：
  - 新增 **2D 攝影機系統**：畫布攝影機疊層、獨立控制視窗、視口預覽與依攝影機取景匯出。
  - 升級 **透光桌 v2（Light Table v2）**：獨立工具視窗與本地參考畫格疊層管理。
  - 新增 **本地音訊引擎（`AudioTrackEngine`）**：時間軸支援攝影機軌與音訊軌同步對位。

### 5. 🎞️ 濾鏡系統重構與 F1–F3 完整濾鏡庫
- **架構重構與效能最佳化**：
  - 建立共享濾鏡註冊表（依 ID 查找像素演算法）、分組選單、常駐濾鏡 Worker 與四語系參數名稱。
  - 大圖層套用濾鏡時提供即時草稿預覽，精緻化計算期間顯示流光掃描指示；最佳化模糊、發光、銳化、柔化與旋轉模糊速度且維持相同輸出結果。
  - 支援在畫布上直接拖曳濾鏡中心點（放射模糊、縮放模糊、球面化等）。
- **新增與升級濾鏡類別**：
  - **色彩調整**：色階（附即時直方圖）、色彩調整預設卡、灰階、閾值、單色著色。
  - **線稿專用工具**：線寬調整（整像素加粗／變細）、去除雜點、抽取線稿、變更線稿顏色、平滑鋸齒。
  - **模糊與銳化**：動感模糊、縮放模糊、旋轉模糊、柔化、精細銳化、高反差保留。
  - **特效與藝術**：放射色散、馬賽克、發光、外框、浮雕、陰影、邊緣線稿、波浪、球面化、扭曲與渲染類濾鏡。
- **工作流增強**：
  - 支援「套用至上方新圖層」（內建記憶體安全保護）。
  - 新增濾鏡縮圖瀏覽庫與個人收藏夾。

### 6. 💬 程序化漫畫對話框幾何引擎
- 新增 `apps/client/src/utils/comicBubbleGeometry.ts`（2,264 行純幾何演算法）並深度整合至 `ComicStudioOverlay.tsx`：
  - 支援程序化生成橢圓、矩形、思考雲、尖刺爆炸等各式漫畫氣球外框與動態尾巴造型。
  - 支援對話框內部排版與直排標點最佳化，大幅提升漫畫分鏡與嵌字效率。

### 7. 📐 圖層對齊、分佈與參考線系統（Align L1 → L2 → L3）
- **L1（單層對齊）**：支援單一圖層依畫布或選區進行整像素對齊，並提供邊緣按鈕與 3×3 九宮格對齊視窗（`LayerAlignWindow`）。
- **L2（多層對齊與分佈）**：支援多圖層批次對齊、8 向等距分佈、圖層群組與遮罩聯動移動，且全部合併為單一步驟復原。
- **L3（參考線與向量／文字精準對齊）**：新增畫布參考線模型與視覺疊層、支援多選向量筆劃與 `textBoxRect` 精準對齊、並提供情境式對齊工具視窗。

### 8. 🧩 外掛系統三代大演進：Plugin API v2 → v2.5 → v3.0
- **Plugin API v2（安全沙盒與完整畫布讀寫）**：
  - 導入 QuickJS 非同步 RPC 沙盒，內建超時與配額保護。
  - 開放圖層樹操作、Tile 像素讀寫、選區幾何與遮罩（`respectSelection`）、交易式 `groupId` 單步復原、外掛濾鏡（F1）、指令／防劫持快捷鍵與宣告式 ToolWindow 面板。
  - 嚴格強制房間 `viewer` 唯讀權限（ACL），並提供官方 v2 範例外掛與說明文件。
- **Plugin API v2.5（動畫、筆刷 v2 與自訂工具）**：
  - 開放時間軸、關鍵幀、緩動曲線註冊表與筆刷 v2 參數 RPC 橋接。
  - 支援外掛註冊自訂繪圖工具（含節流指標工作階段、工具列入口與快捷鍵），並附官方 v2.5 範例套件。
- **Plugin API v3.0（桌面專屬本地工具 Bridge 與 Loopback MCP）**：
  - **Electron 主程序隔離橋接（`pluginV3Bridge.ts`）**：僅允許透過原生對話框綁定並通過 SHA-256 雜湊驗證的可信執行檔；封鎖 shell 直譯器、強制 `shell:false`、臨時目錄沙盒、`realpath` 路徑逃逸檢查與環境變數淨化。
  - **本機 Loopback MCP Server／Client**：預設唯讀、支援 Token 輪換、設定一鍵複製，具備 DNS Rebinding / CSRF / 401 防護，畫布寫入強制經由 `PluginCanvasTransaction`（受 ACL、單步 Ctrl+Z 與穩定器不可變性保護）。
  - **安全授權與緊急熔斷**：新增兩階段確認彈窗（`PluginV3ConsentModal`：拒絕／單次允許／本次會話允許）、桌面控制台（`PluginV3BridgeModal`）、高風險權限標章與一鍵「停止所有橋接」Kill Switch；在 Web、手機端與多人協作房間自動降級或封鎖。

### 9. 🌐 多人協作權限、跨伺服器主帳號與連線／離線穩定性
- **房間成員角色權限（ACL）**：
  - 前後端與共享層新增畫布成員角色 DTO、管理 API、即時同步徽章與內聯角色切換器。
  - `viewer` 角色具備即時唯讀保護（畫布、伺服器與外掛三層攔截）。
- **跨伺服器主帳號與網路隱私安全**：
  - 伺服器於 `/api/server/identity` 以金鑰簽章驗證客戶端挑戰，安全情境下可跨伺服器與不同連線網址自動延續主帳號、暱稱與頭像。
  - `/api/server/network` 不再向遠端訪客暴露主機 LAN / VPN 位址，並排除 `169.254.x.x` 鏈路本地位址。
  - 透過遠端分享連結開啟的網頁鎖定協作模式，僅本機 App 或 `localhost` 開放單機模式。
- **入口畫廊與聯機體驗**：
  - 新增「繼續上次畫作」卡片與最近畫布畫廊、記憶最後開啟的畫布與房間，點擊即可直達目標畫布（不再先經過列表第一個）。
  - 頂部列與入口新增「聯機」入口與三種連線引導（同 Wi-Fi、虛擬區網、公開連結）；介面完整依目前語系顯示 API 錯誤訊息。
  - 修正建立新房間時不再自動加入既有房間。
- **離線與線上工作區隔離修復（v1.3.0）**：
  - 新增 `roomJoinGuard.ts` 並強化 `offlineStore.ts`，徹底隔離離線儲存與線上 UUID。
  - 修復新建圖層的復原紀錄遺失問題，並加入非破壞性離線分頁關閉機制。

### 10. 🛠️ 打包流程修復、細節修補與測試品質提升
- **macOS 打包與自動發佈修復**：修正 `better-sqlite3` v13 N-API prebuild 路徑檢查（`prebuilds/darwin-<arch>.node`），並設定推送版本標籤時自動建置 `arm64` 與 `x64` 兩份 `.pkg` 並附加至 GitHub Release；停止上傳多餘的 SHA256SUMS 檔案。
- **Android 打包支援**：`scripts/package-android.mjs` 支援解析預發布版本尾碼（如 `1.2.8-beta`）計算 `versionCode`。
- **UI 細節修復**：修復參考視窗標題列按鈕因拖曳事件捕獲而無法點擊的問題；修正 `AnimationExportModal` 透過 Portal 掛載至 `body` 防止流光溢位。
- **自動化測試與安全稽核**：
  - 前端單元測試擴增並全數通過（85/85），涵蓋觸控手勢、漫畫幾何、Procreate 解析、動態與表面材質、濾鏡、對齊 L3、房間加入守衛等。
  - 建立涵蓋 Web 5 視口 × 4 語系、手機獨立模式、LAN `net-proxy` 多人 ACL、隔離式 Electron 桌面冒煙測試，以及 Plugin API v3.0 專屬安全性測試（反 shell 注入、反路徑穿越、DNS Rebinding/CSRF 防護等）。
