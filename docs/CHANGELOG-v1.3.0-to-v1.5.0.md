## 二、v1.3.1 → v1.3.2：檔案匯入與圖層操作穩固

### 1. 多圖層專案匯入（`.psd`／`.kra`）
- **支援 Adobe Photoshop（`.psd`）與 Krita（`.kra`）匯入**：保留圖層樹、巢狀資料夾、混合模式、不透明度、顯示狀態、剪裁遮色片、透明鎖定，以及圖層／群組蒙版。
- **多元開啟方式**：單機工作區與多人聯機工作區皆支援直接拖曳檔案至視窗、透過「檔案」選單或 `Ctrl+O` 匯入。
- **Krita 剪裁相容修正**：支援解析 `.kra` 的 `inheritsalpha`（並相容 `inheritalpha`／`inheritAlpha`），將其正確轉換為 `clipToBelow` 剪裁遮色片。

### 2. 圖層面板多選與編組順序修正
- **`Shift + 左鍵拖曳` 連續多選**：掃過多列圖層即可連續選取，拖曳至清單上下緣自動捲動；搭配 `Ctrl+Shift` 可於既有選取上加選。
- **非連續圖層編組與批次移入順序保持**：透過 `layer-tree.ts` 排序規劃修正 `groupLayers` 與 `moveLayersToGroup` 逐層移動時上下順序顛倒的問題，並確保收合群組時正確隱藏子圖層。
- **單機專案還原防誤刪**：`offlineStore.createCanvas` 改回傳圖層快照，還原 `.lumina`／`.psd`／`.kra` 時完整保留首張匯入根圖層。
- **伺服端權限測試補強**：驗證已認證帳號的貼圖同步與匿名訪客寫入拒絕（`PERMISSION_DENIED`）。

## 三、v1.4.0：專業繪圖工具組、輔助面板、調整圖層與色彩管理

### 1. 主工具列與輔助工具集架構
- **精簡主分類工具列與經典模式切換**：左側工具列改為分類收斂架構（保留「經典展開模式」切換），每個主分類自動記憶上次使用的子工具；重複按同一分類快捷鍵可於組內循環切換，並各自保存獨立工具參數至 `localStorage`。
- **選取與向量工具補齊**：
  - 新增**矩形選框**、**橢圓選框**（`Shift` 等比、`Alt` 中心展開）與**多邊形套索**（逐點連線、`Backspace` 退點、雙擊／`Enter` 閉合、`Esc` 取消），全部 7 個選取子工具統一支援取代／加選／減選、消除鋸齒與羽化。
  - 向量工具組補齊 6 個子工具，其中**向量橡皮擦**支援「擦至交點／局部擦除／整條刪除」三種模式。
- **快捷鍵分層設計**：於設定視窗拆分「主工具分類」與「個別子工具」快捷鍵，預設零衝突並與 Plugin API v2.5 自訂工具相容。

### 2. 繪師高頻輔助面板
- **子視圖（Sub View）參考圖面板**（`Ctrl+Shift+R`）：可停靠 Dock 或浮動顯示，支援拖曳／選檔／剪貼簿載入多張參考圖切換，獨立縮放、平移、水平翻轉、旋轉與游標移入自動吸色；資料保存於本機 IndexedDB，不佔多人房間頻寬。
- **色彩歷史與迷你混色盤（Mixing Pad）**：自動紀錄近期用色、支援固定常用色票組與 `.aco`（v1/v2）／`.gpl` 色票檔雙向匯入匯出；迷你混色盤提供獨立揉色調色區並可即時吸色。
- **桌面快顯輪盤（Pop-up Palette）**：於游標處喚出「HSV 色環＋近期色票＋常用筆刷／子工具」三層輪盤，具視窗邊界防裁切定位，可於設定自訂右鍵／數位筆側鍵／`Alt+Q` 觸發方式。

### 3. 速寫、修形與無縫材質三大工具
- **快速形狀（QuickShape）**：收筆短暫停頓即可自動辨識並吸附為直線、圓弧、圓形、橢圓、三角形與四邊形，按住拖曳可即時微調角度與尺寸，並支援設定開關與停頓延遲。
- **操控變形（Puppet Warp，`Ctrl+Alt+P`）**：依圖層非透明區域或選區自動建構三角網格，支援新增／拖曳／刪除釘點與旋轉權重，採 ARAP（As-Rigid-As-Possible）演算法降低扭曲與黑邊，確認後單步寫入 Tile 並同步多人房間。
- **四方連續平鋪（Wrap-Around，`Alt+W`）**：提供 3×3 無縫平鋪即時檢視，筆刷、橡皮擦、揉色、模糊、油漆桶與形狀工具均支援跨邊界環繞繪製與多人同步。

### 4. 非破壞性調整圖層
- 支援 **6 種即時調整圖層**：色相／飽和度／明度（HSL）、色階（Levels）、色調曲線（Curves，RGB 與單通道）、色彩平衡（Color Balance）、漸層對應（Gradient Map）、亮度／對比（Brightness/Contrast）。
- 完整支援不透明度、混合模式、剪裁遮色片（`clipToBelow`）、圖層／群組蒙版與群組隔離，GPU 即時預覽與匯出公式對齊；雙擊可隨時重編參數且不更動原始像素，支援單步復原、多人同步、`.lumina` 存讀與 `.psd` 常見調整層互通。

### 5. 自動動作（Auto Actions）與富文本排版引擎
- **自動動作／巨集**：可停靠 Dock 或行動端面板，支援錄製、暫停、連續滑桿合併、步驟排序與單步停用；涵蓋 12 種常用圖層／濾鏡／調整／選區指令，內建 7 組實用預設並支援 `.lumina-action` JSON 匯入匯出。整段播放包裹於單一 `groupId` 交易，一次 `Ctrl+Z` 即可完整復原，出錯自動回滾。
- **富文本文字引擎**：支援局部區段樣式（字色、字級、粗斜體）、字距與行距調整、左／中／右對齊、可拖曳固定文字方塊自動換行、**描邊置後（Stroke behind Fill）**、陰影效果，以及直排（縱書）漫畫標點避頭尾、括號旋轉與小寫假名處理。

### 6. CMYK 軟校樣、ICC 嵌入與雙向 `.kra` 匯出
- **本機 CMYK 軟校樣與超色域警告**：透過「檢視 → 色彩校樣」即時開關（僅作用於本機視口，不干擾多人房間或吸管／填色像素）；內建 Japan Color 2001 Coated、FOGRA39、US Web Coated SWOP 近似模型，並支援載入自訂 `.icc`／`.icm`（支援 ICC v2/v4 lut8/lut16/mAB/mBA/matrix-TRC 與 `gamt`）。
- **RGB ICC 描述檔嵌入**：PNG（`iCCP`）、JPEG（`APP2`）與 PSD 匯出支援嵌入標準 sRGB 或自訂 RGB ICC 描述檔。
- **雙向 Krita `.kra` 無損匯出**：原生寫出標準 `.kra` 封裝（STORE `mimetype`、`maindoc.xml`、`mergedimage.png`、`preview.png`、`VERSION 2` 64×64 Planar BGRA + LZF 瓦片、`.pixelselection` 透明度蒙版），保留群組階層、27 種混合模式、繼承 Alpha 剪裁、透明鎖定、背景色與 DPI。

## 四、v1.5.0：進階專業功能、多人繪茶 2.0、大畫布效能與實機打磨

### 1. 圖層面板色標、草稿染色與「用紙」底色系統
- **8 色圖層／群組面板色標**：快速標記線稿、底色、陰影與背景群組，於單機與多人房間同步保存。
- **非破壞性圖層顯示色彩（Draft Tint）**：一鍵將草稿或線稿圖層以主色／副色即時染色顯示而不改動原像素，支援 GPU 濾鏡預覽與匯出一致性。
- **「用紙（Paper）」底色系統**：即時切換畫布底色與透明格紋顯示，並於多人房間即時廣播同步。

### 2. 尺規系統 v2（純 2D，不含 3D 幾何／人偶）
- **集中線／放射狀尺規與曲線／貝茲特殊尺規**：支援放射狀筆劃吸附、貝茲曲線切線吸附與多段控制點拖曳編輯。
- **圖層綁定尺規**：支援三種作用範圍（顯示於全部圖層／僅在同資料夾／僅在目標圖層）。
- **純 2D 透視空間網格**：支援 1／2／3 點透視、`xy`／`xz`／`yz` 三平面獨立開關、可拖曳基準點與畫布範圍裁剪。

### 3. 可伸縮懸浮圖標小球與膠囊 Dock
- 任一浮動工具面板可一鍵縮成高辨識度圖標小球，多個小球可磁吸合併為可切換橫向／直向的膠囊 Dock，支援點擊快速展開切換與拖出拆球，有效釋放畫布繪圖空間。

### 4. 筆刷引擎 v3 與跨軟體筆刷格式深度支援
- **核心筆刷能力升級**：新增雙筆刷（Dual Brush）紋理疊加、色彩動態（色相／飽和度／明度／前後景抖動）、水彩濕邊（Wet Edge）、Kubelka-Munk 減色顏料混色，以及多筆尖隨機／循環輪播。
- **生態筆刷格式匯入強化**：大幅提升 Clip Studio Paint（`.sut`）與 Procreate（`.brushset`）筆刷檔的解析與參數還原度，自動對應筆尖形狀、間距、動態曲線與雙筆刷設定。
- **Adobe Photoshop `.abr`（v6.2）筆刷匯出**：新增單支筆刷與多筆刷群組 `.abr` v6.2 匯出，方便與外部繪圖生態交換自訂筆刷組。

### 5. 非破壞性圖層樣式、快速遮色片與色域選取
- **4 種非破壞性圖層樣式（Layer Effects）**：支援**邊界效果（銳利描邊／水彩邊界）**、**陰影**、**外發光**與**色彩覆蓋**，完整串接 GPU 即時預覽、PNG/WebP/PSD/KRA 匯出、多人即時廣播與分享預覽圖。
- **快速遮色片（Quick Mask，`Q`）**：一鍵進入紅寶石半透明遮罩模式，以筆刷／橡皮擦精細加減選區而不破壞原圖層像素，結束後轉為選區並支援 Undo/Redo；切換畫布時自動重置狀態，並修正調整圖層標題列跳動問題。
- **色域選取（Color Range）與 WebP 匯出**：提供即時遮罩預覽、畫布滴管取色、容差／羽化／反相調整與一鍵建立選區；同步新增單張 WebP 匯出。

### 6. 多人繪茶 2.0 協作體驗
- **跟隨繪師視角（Follow Camera）**：精準同步目標畫師的平移、縮放、旋轉、水平鏡像與 DPI 座標；按 `Esc` 或手動拖曳視窗即時解除，目標離線自動退出。
- **分格認領／接龍格線（Grid Slots）**：房主／管理員可建立 `M×N` 接龍分格，畫友一鍵認領、自動對焦至格位或釋放，具伺服端衝突防護與 RBAC 權限控管。
- **房間共用色票盤與共用參考圖板**：支援房間級色票同步與共用參考圖位置／縮放同步及管理員鎖定，與個人本機 Sub View 嚴格隔離。

### 7. 動畫時間軸音訊波形與 MP4／WebM 混音匯出
- **高 DPI 真實音訊波形時間軸**：以 `<canvas>` 繪製真實波形，即時反映裁剪起點（`trimStartSec`）、結束幀、音量縮放（含原音量幽靈外框）、靜音狀態與播放頭進度；支援於時間軸直接橫向拖曳音軌起始幀與行內快速靜音。
- **離線立體聲 PCM 混音與影片封裝**：支援跨取樣率重取樣與 `tanh` 軟限幅，透過 WebCodecs `AudioEncoder` + `mp4-muxer`（AAC／Opus）與 `webm-muxer`（Opus）匯出含音軌影片；若裝置不支援編碼器或無音軌則安全降級為純影像並提示。

### 8. 商業印刷真 CMYK 4 通道分色匯出與 TAC 警告
- **GCR／UCR 黑版分色模型**：內建 Japan Color 2001 Coated（300%）、FOGRA39（330%）、US Web Coated SWOP（300%）與自訂參數（黑版強度、起始點、最大黑墨量、TAC 上限與自動限墨）。
- **真 4 通道 CMYK 編碼器**：支援無損 PackBits **Baseline TIFF 6.0（`PhotometricInterpretation = 5`、`SamplesPerPixel = 4`、DPI 與可選 ICC Tag）**與 **CMYK PSD（`ColorMode = 4`、保留各點陣圖層與混合模式）**。
- **即時 TAC 超限熱點預覽**：於匯出視窗內嵌下採樣 TAC 熱圖畫布、峰值總墨量、超限面積佔比與四語系警告提示。

### 9. 超大畫布（4K～13K）效能、記憶體池化與穩定度突破
- **Tile GPU LRU 記憶體池化**：導入雙上限（最大 Tile 數＋VRAM 位元組）與 85% 低水位遲滯策略，優先零 `readPixels` 淘汰 Clean 離屏 Tile；新增 `TileAtlas` 閒置紋理頁溫熱重用池與 4K+ 自適應 PBO 池化。
- **13500×7800（50 圖層）載入／繪製／復原加速與縮放清晰度修復**：大幅加速超高解析度多圖層載入、落筆與 Undo 速度，並修復大幅縮小時 Mipmap 淡化失真問題。
- **13500×7500 行動端與多人 OOM／WebGL 紋理上限防護**：避免超高解析畫布於行動端或多人聯機時觸發 WebGL 單紋理尺寸上限或記憶體耗盡崩潰。

### 10. 即時畫布導覽器、字型庫升級與實機複測打磨
- **即時畫布導覽器（Navigator Panel）**：新增即時縮圖預覽、可拖曳視口紅框、縮放滑桿、旋轉控制與**垂直翻轉**支援。
- **字型庫與文字方向升級**：新增本機系統字型掃描、可搜尋字型選擇器、字型分類與橫書／直書快速切換。
- **工具列與輔助工具集全面統一精簡**：
  - 折疊精簡主工具列擴充為 14 大類，將**文字、漫畫、動畫**直接獨立顯示於主工具列。
  - 統一輔助工具集面板標題、加入清晰視覺分隔線並精簡冗餘描述文字。
  - **單一油漆桶屬性雙向同步**：整併原「參照其他圖層／僅參照編輯圖層」為單一「油漆桶」子工具，上方工具選項列與側邊工具屬性同步切換參照模式。
  - **智能填色整合**：整合「圍住塗抹」與「間隙補塗」於同一智能填色工具中，可於屬性快速切換模式。
